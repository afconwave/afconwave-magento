# AfconWave Payment Gateway for Magento 2

Official Magento 2 module for the AfconWave Secure Gateway.

## API keys

Use dashboard keys only:

- Secret sandbox: `afc_sk_test_...`
- Secret live: `afc_sk_live_...`
- Public sandbox: `afc_pk_test_...`
- Public live: `afc_pk_live_...`

Do not use `afw_` prefixes. The API authenticates `afc_sk_` only.

## Configuration

Stores → Configuration → Sales → Payment Methods → AfconWave Secure Gateway.
